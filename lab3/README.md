# lipo-ols — липофильность и линейная регрессия

Лабораторная работа №3. Пакет оценивает зависимость коэффициента
липофильности $\log P$ от 24 структурных дескрипторов молекул (табл. 1
методички) методом наименьших квадратов по выборке [`lipo.csv`](../lipo.csv).
Он находит остатки, $s^2$, $s$, $R^2$, доверительные интервалы коэффициентов
по t-статистике, проверяет условия применимости МНК и сравнивает результат
со статьёй López, Pinheiro, Zamora (2021). Все расчёты сделаны своим кодом
по формулам лекции 3 и сверены с пакетом `statsmodels` (раздел 4.5 отчёта).

**Отчёт с результатами и ответами на вопросы пункта 7 — [REPORT.md](REPORT.md),
он же в PDF — [REPORT.pdf](REPORT.pdf).**

```python
from lipo_ols import load_lipo, fit_ols_data

data = load_lipo()            # пункт 1: 82 вещества, 24 регрессора
fit = fit_ols_data(data)      # пункт 2: b = (XᵀX)⁻¹Xᵀy
fit.residuals                 # пункт 3: e = y − Xb
fit.s2, fit.s                 # пункт 4: 0.591, 0.769
fit.r2                        # пункт 5: 0.838
fit.conf_int(0.95)            # пункт 6: b ± SE(b)·t, массив 25 × 2
```

## Установка

Нужен Python ≥ 3.9, NumPy, SciPy и Matplotlib; для сверки с пакетом —
statsmodels (ставится вместе с тестовыми зависимостями).

```bash
python3 -m venv .venv
.venv/bin/pip install -e ".[test]"
```

Без установки достаточно добавить `src` в `PYTHONPATH`:
`PYTHONPATH=src python -m lipo_ols fit`.

Файл с выборкой ищется в корне репозитория (`../lipo.csv`); другой путь
задаётся ключом `--data` или переменной окружения `LIPO_CSV`.

На macOS 26 (Apple M1) колёсико SciPy 1.15.3 не загружается, SciPy 1.14.1
работает: `pip install "scipy==1.14.1"` (как в ЛР2).

## Командная строка

```bash
python -m lipo_ols fit                                  # пункты 2–6: таблица коэффициентов, s², s, R², F
python -m lipo_ols fit --columns C PSA HBA1 --level 0.99  # часть регрессоров, 99%-е интервалы
python -m lipo_ols fit --method qr --json               # МНК через QR, вывод в JSON
python -m lipo_ols residuals --sort                     # пункт 3: остатки по веществам
python -m lipo_ols diagnostics                          # пункт 7: условия применимости МНК
python -m lipo_ols report                               # все рисунки и таблицы отчёта (≈ 10 с)
```

## PDF-версия отчёта

```bash
pip install -e ".[pdf]"          # pandoc (pypandoc_binary) и pypdf
python -m lipo_ols report        # пересчитать рисунки и results/tables.md
python tools/fill_tables.py      # подставить таблицы в REPORT.md
python tools/build_pdf.py        # REPORT.md -> REPORT.pdf (нужен Google Chrome)
```

Таблицы в `REPORT.md` не набираются вручную: они стоят между комментариями
`<!-- table:N -->` и `<!-- /table -->` и заполняются из `results/tables.md`.
`python tools/fill_tables.py --check` проверяет, что они актуальны.

## Тесты

```bash
python -m pytest                       # 94 теста, ≈ 10 с
python -m pytest --doctest-modules src # примеры из докстрингов
ruff check src tests
```

| Файл | Что проверяет |
|---|---|
| `test_data.py` | чтение файла, структура, десятичный логарифм, редкие регрессоры, повторы строк X, ошибки формата |
| `test_ols.py` | три способа решения МНК, $X^Te = 0$, $s^2$, $R^2$, SE, интервалы (покрытие 95 % на синтетике), F-тесты |
| `test_distributions.py` | плотности Стьюдента и Фишера по формулам лекции, квантили против SciPy |
| `test_diagnostics.py` | рычаги, стьюдентизированные остатки и расстояние Кука против явного удаления точки, VIF, тесты на синтетических нарушениях |
| `test_validation.py` | скользящий контроль против формулы $e_i/(1-h_{ii})$, k-кратная проверка, пошаговое исключение |
| `test_contributions.py` | стандартизованные коэффициенты, $\Delta R^2$, пары молекул |
| `test_literature.py` | воспроизведение статистик MLR-1, MLR-2, MLR-3 из статьи [2] |
| `test_package_compare.py` | совпадение всех величин со `statsmodels` до $10^{-9}$, особые точки с $h = 1$ |
| `test_cli.py`, `test_plots.py` | командная строка, генерация отчёта, рисунки |

## Что сделано по пунктам задания

| 2. МНК-оценки $b_i$ | `ols.solve_ols` (нормальные уравнения; проверено QR и $X^+$); табл. 2 |
| 3. МНК-остатки $e$ | `OLSResult.residuals`; приложение, табл. П1; `results/residuals.csv` |
| 4. $s^2$ и $s$ | `OLSResult.s2`, `OLSResult.s`; раздел 3.2 |
| 5. $R^2$ | `OLSResult.r2` (+ скорректированный и нецентрированный); раздел 3.2 |
| 6. Доверительные интервалы по t-статистике | `OLSResult.conf_int`; квантиль по формуле лекции — `distributions.student_quantile`; табл. 2, рис. 3 |
| 7. Адекватность модели | раздел 4.1: F-тест, скользящий контроль, 5-кратная проверка, пошаговое исключение, чистая ошибка |
| 7. Вклад регрессоров | раздел 4.2: стандартизованные коэффициенты, $\Delta R^2$, пары молекул, сравнение с теорией |
| 7. Условия применимости МНК | раздел 4.3: RESET, VIF, Бройш–Паган, Дарбин–Уотсон, Шапиро–Уилк, рычаги, Кук |
