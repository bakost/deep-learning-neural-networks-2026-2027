# level-spacing — свойства случайных матриц

Лабораторная работа №2. Пакет генерирует ансамбли случайных симметричных
матриц (гауссов ортогональный ансамбль и матрицы из ±1), находит расстояния
между фиксированной парой соседних собственных чисел, нормирует их и
сравнивает с догадкой Вигнера $\rho(s) = \frac{\pi s}{2} e^{-\pi s^2/4}$.

**Отчёт с результатами и выводами — [REPORT.md](REPORT.md), он же в PDF —
[REPORT.pdf](REPORT.pdf).**

Генерируемый ансамбль $H = A + A^T$ — гауссов *ортогональный* ансамбль:
распределение $Q^T H Q$ совпадает с распределением $H$ для любой
ортогональной $Q$ (доказательство и проверка — раздел 2 отчёта).

```python
from level_spacing import run_study

study = run_study("goe", n=16, size=100_000, seed=2026)   # пункты 1–4
study.k                          # 8 — центральная пара (λ8, λ9)
study.normalized.mean()          # 1.0
study.compare("wigner")          # D_KS, χ², L1 до формулы (15)  — пункт 8
study.compare("goe-limit")       # то же до точного закона GOE при n → ∞
```

## Ансамбли

| Имя | Построение | Ортогональный | Где в задании |
|---|---|---|---|
| `goe` | $A_{ij} \sim \mathcal N(0,1)$, $H = A + A^T$ (раздел 1.3 методички) | **да** | пункты 1–8 |
| `pm1` | симметричная матрица, $H_{ij} = \pm 1$ | нет | пункт 9, трактовка (а) |
| `pm1-sum` | $A_{ij} = \pm 1$, $H = A + A^T$ | нет | пункт 9, трактовка (б) |
| `normal-mirror` | симметричная матрица, $H_{ij} \sim \mathcal N(0,1)$ | нет | сравнение: зачем $A + A^T$ |

Ортогональность проверяет `orthogonal_invariance()`, случайные
ортогональные матрицы (Грам–Шмидт/QR с поправкой знаков, мера Хаара) даёт
`random_orthogonal()`.

## Тесты

```bash
python -m pytest                                       # 224 теста, ≈ 13 с
PYTHONPATH=src python -m pytest --doctest-modules src  # 28 примеров из докстрингов
ruff check src tests
```

| Файл | Что проверяет |
|---|---|
| `test_ensembles.py` | форма, симметрия, распределение элементов (дисперсии 4 и 2 у $A + A^T$), воспроизводимость |
| `test_orthogonality.py` | ортогональность ансамбля: $Q^T H Q$ распределена как $H$ только для GOE; генератор ортогональных $Q$ |
| `test_spectrum.py` | собственные числа (формулы (4), (5)), нумерация пар, нормировка, бэкенд Якоби |
| `test_distributions.py` | формулы (13)–(15), нормировка и моменты законов, точный закон GOE (дисперсия 0.2855, наклон $\pi^2/6$) |
| `test_exact.py` | полный перебор ±1, совпадение аналитики пункта 10 с перебором и моделированием |
| `test_stats.py` | критерии согласия, поправка Лиллиефорса, оценка показателя отталкивания |
| `test_experiments.py` | главные выводы отчёта: 2×2 = Вигнер, 16×16 ≠ Вигнер, 16×16 = GOE$_\infty$, универсальность |
| `test_cli.py`, `test_plots.py` | командная строка и рисунки |

Статистические тесты используют фиксированные зёрна и поэтому
детерминированы.
